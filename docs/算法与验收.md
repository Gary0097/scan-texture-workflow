# 算法、参数和限制

1. 扫描修补：根据 stamp-patches.json 的目标矩形和偏移，复制原扫描邻域。坐标只适用于本次样本；不是生成式补图，也不是 Photoshop 图章笔刷。repair-scan.py 是交接时新增的等价数组复制入口，未全图回归。
2. 局部频域去线：192 像素窗口，48 像素步长，Hann 加权重叠重建；寻找主频并抑制 1–3 次谐波，保留低频。单独这一版残线明显，必须继续下一步。
3. 亮点及残线：对灰度 >=220 的连通区域从干净邻域复制修补，再做 sigma=12 px 平滑。早期要求 >240，后续为覆盖约225的亮点改成220。会损失相近尺度的底纹，不能宣称完全恢复被线条遮挡的原纹理。无干净供体时停止。
4. 无缝：半幅移位，把接缝移到内部；同源供体条带沿低误差曲线拼接，600 px 过渡，随后移回。非镜像。像素边界连续不等于整体自然，仍需看3×3重复和斜光。
5. 新线层：用户改为允许重新生成，不再描摹扫描。用周期调制场和闭合曲线生成变宽黑色带；NY=1320、NX=850，约27度走向，宽度占比约0.28–0.64。SVG 为闭合贝塞尔路径；PNG/TIFF 为0/255二值。缩小显示可能呈灰或摩尔纹，必须看原尺寸局部。
6. 组合：底图保持16位；线层独立。正片叠底仅是二维视觉合成，不是将刀线转换为合适的雕刻槽深。

## 验收

- 底图：确认亮点、切割残线、过度平滑，以及3×3的竖条、暗格和花纹突变。
- 线层：0/255、无孔洞和交叉，跨边位置和切线连续；查看生成与检查记录。数学周期误差很小并不代表生产工艺已验收。
- 灰线：本次灰值128为试调值，不是从扫描精确标定。确认整体反差后再定稿。
- 3D：用相同物理尺度和高度，检查真实位移，不能只看材质凹凸。

## 时间和资源

暂无统一硬件上的重复基准测试，不提供平均耗时或GPU用量承诺。各算法已有局部运行计时，见 reports，不能跨机器直接套用。主要使用CPU、内存、磁盘；Blender渲染另计。

全尺寸单层16位原始像素约570 MB，中间数组、多个图层会占数GB甚至更多。建议至少32 GB内存、预留20 GB磁盘（建议值而非最低要求）。SVG约195 MB，导入矢量编辑器可能很慢。不要同时重算多个全尺寸步骤。复用已确认底图可省掉最耗时部分。
